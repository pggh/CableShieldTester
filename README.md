# CableShieldTester

This is a simple build-it-yourself device that allows you to test
whether a cable is shielded or not. The device is easy and fast to use,
however, depending on the connector type you are dealing with, you need
a connector or adapter to get access to the signal lines.
There must be nothing connected to the other side of the cable.

The design is based on an ATtiny84 micro-controller so you will need a
programmer for it to build your device. (Any of the ATtiny24, ATtiny24A,
ATtiny44, ATtiny44A, ATtiny84, ATtiny84A will work.)
